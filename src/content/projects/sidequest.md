sidequest. is a Python & React web-app designed to help users find the cheapest flights to their destination.
It leverages layovers as not only a cost-saving strategy, but also an opportunity for travelers to find a better use of their time while waiting for their connecting flight.
The app uses the Skyscanner API to find flights, and Google Gemini's API to plan an itinerary for each layover on the way.
